## Workflow

Processing data

- [`dem_region()`](https://bcgov.github.io/bcaquiferdata/dev/reference/dem_region.md)
  : Fetch and trim DEM of a region
- [`wells_eg_fixed`](https://bcgov.github.io/bcaquiferdata/dev/reference/wells_eg_fixed.md)
  : wells_eg_fixed
- [`wells_eg_unfixed`](https://bcgov.github.io/bcaquiferdata/dev/reference/wells_eg_unfixed.md)
  : wells_eg_unfixed
- [`wells_elev()`](https://bcgov.github.io/bcaquiferdata/dev/reference/wells_elev.md)
  : Subset wells and add elevation
- [`wells_export()`](https://bcgov.github.io/bcaquiferdata/dev/reference/wells_export.md)
  : Export wells data for use in Strater and Voxler
- [`wells_subset()`](https://bcgov.github.io/bcaquiferdata/dev/reference/wells_subset.md)
  : Subset wells to region
- [`wells_yield()`](https://bcgov.github.io/bcaquiferdata/dev/reference/wells_yield.md)
  : Add yield lithology data to wells subset

## Helper Functions

- [`fix_depth_mismatch()`](https://bcgov.github.io/bcaquiferdata/dev/reference/fix_depth_mismatch.md)
  : Fix the depth of the well if not equal to final lithology
- [`fix_yield_zero()`](https://bcgov.github.io/bcaquiferdata/dev/reference/fix_yield_zero.md)
  : Fix the yield of a well if equal to zero

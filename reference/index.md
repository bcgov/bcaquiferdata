## Dealing with Data

Download and manage data

- [`data_read()`](http://bcgov.github.io/bcaquiferdata/reference/data_read.md)
  : Download, Update, and/or load data
- [`data_update()`](http://bcgov.github.io/bcaquiferdata/reference/data_update.md)
  : Update cached data
- [`cache_clean()`](http://bcgov.github.io/bcaquiferdata/reference/cache_clean.md)
  : Clean cache

## Workflow

Processing data

- [`dem_region()`](http://bcgov.github.io/bcaquiferdata/reference/dem_region.md)
  : Fetch and trim DEM of a region
- [`wells_elev()`](http://bcgov.github.io/bcaquiferdata/reference/wells_elev.md)
  : Subset wells and add elevation
- [`wells_export()`](http://bcgov.github.io/bcaquiferdata/reference/wells_export.md)
  : Export wells data for use in Strater and Voxler
- [`wells_subset()`](http://bcgov.github.io/bcaquiferdata/reference/wells_subset.md)
  : Subset wells to region
- [`wells_yield()`](http://bcgov.github.io/bcaquiferdata/reference/wells_yield.md)
  : Add yield lithology data to wells subset
